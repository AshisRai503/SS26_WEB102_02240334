# WEB102 P1: Reflection - RESTful Social Media API Design

## Documentation: Concepts Applied

In this practical, I applied the following main concepts:

- RESTful API principles
- Resource-based URI design
- HTTP methods and status codes
- Middleware
- Controllers and routes
- Centralized error handling
- Content negotiation

These concepts helped me understand how the practical works beyond only copying the code. I was able to connect the theory from the report with the actual implementation steps.

## What I Learned

I learned how to use RESTful API principles, Resource-based URI design, and http methods and status codes. I also learned that a working project depends on correct folder structure, correct package installation, and careful testing after every main change.

## Challenges Faced

- Designing clean URI patterns for resources
- Handling pagination metadata and next/previous links
- Maintaining consistent error responses

## How I Overcame the Challenges

- Used plural resource names such as `/users` and `/posts`.
- Used HTTP methods instead of verbs in URLs.
- Calculated pagination values using page and limit query parameters.
- Used middleware to standardize error responses.
