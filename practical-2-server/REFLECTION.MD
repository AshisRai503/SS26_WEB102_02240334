# WEB102 P2: Reflection - TikTok RESTful API Backend with Express

## Documentation: Concepts Applied

In this practical, I applied the following main concepts:

- RESTful API design
- CRUD operations
- Express routing
- Controllers
- Middleware
- In-memory models
- HTTP request testing

These concepts helped me understand how the practical works beyond only copying the code. I was able to connect the theory from the report with the actual implementation steps.

## What I Learned

I learned how to use RESTful API design, CRUD operations, and express routing. I also learned that a working project depends on correct folder structure, correct package installation, and careful testing after every main change.

## Challenges Faced

- Missing file paths broke require chains
- Middleware order caused route issues
- PowerShell curl command syntax caused confusion
- Understanding REST status codes through testing

## How I Overcame the Challenges

- Checked file names and imports carefully.
- Kept the app structure separated into models, controllers, and routes.
- Used Command Prompt when curl syntax was easier there.
- Read error messages and tested endpoints one by one.

## Possible Future Improvements

- Replace in-memory data with PostgreSQL.
- Add validation middleware.
- Add authentication for protected endpoints.

## Final Reflection

This practical improved my understanding of backend API development. It also showed me the importance of writing organized code, testing each feature step by step, and documenting the work clearly in GitHub. The practical was useful because it connected classroom theory with real implementation work.
